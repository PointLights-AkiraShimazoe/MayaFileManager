# 見送った変更の置き場

ここにあるものは **製品には入っていません**。理由と、入れる時の条件を残すための控えです。

## sort_filter_path_memo.patch（2026-11-12、v0.9.20 の整理で見送り）

- 中身: 並べ替え（lessThan）と絞り込み（filterAcceptsRow）が、同じ親フォルダのパスを
  毎回根まで辿って組み立てていたのを、親ごとに 1 回で済ませる。結果の並び・絞り込みは
  旧コードと完全に同じ（24 通りの操作・1,031 件の名前で突き合わせ済み）。
- 効果（Linux 計測）: フォルダ移動時の処理時間が約半分（16 回の移動で 3.1 秒 → 1.3 秒）。
- 見送った理由: 大量更新の見張り（ui/fs_churn_guard.py）が効かなくなる。見張りは
  «100ms の脈拍の遅れ» で UI の重さを測っており、1 回あたりの処理が 0.23 秒 → 0.10 秒に
  縮むと遅れに現れない。その結果、P4V の取得のような連続書き込みの間、監視が止まらず
  UI が 0.1 秒刻みで詰まり続ける（7 秒中 6 秒が処理中。test_fs_churn_guard が落ちる）。
- 入れる条件: 見張りの重さの測り方（脈拍の遅れ → 処理に使った時間の割合）を一緒に直し、
  チェックリスト K-3 / K-4（P4V の取得中に固まらない）を実機で確かめる。
- test_sort_filter_path_memo.py.txt: この変更用の回帰テスト（入れる時に tests/offscreen/ へ）。
