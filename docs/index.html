MayaFileManager — 構造図とワークフロー

ワークフローは「ユーザーが何をして、ツールが何をするか」の視点。各図の左サイドバー「FILES」から、カードに対応する実装ファイルを VS Code で開けます（Alt+P で開閉）。

ワークフロー 1起動してフォルダを見る起動 → 前回の状態を復元 → プリセット / ブックマークで移動 → カラム表示 → 連携バッジ ワークフロー 2ファイルを Maya / Blender へ送るクリック / 右クリック / D&D → 送り先と接続を確認 → 前の操作の完了を待つ → 開く・取り込む・保存 → 結果表示 ワークフロー 3ファイルを整理する選ぶ → コピー / 貼付 / 削除 / 名前変更 / 複製 / 新規作成 → 進捗付きで実行 → Ctrl+Z で元に戻す ワークフロー 4Git / SVN / Perforce と連携するバッジで状態を見る → 右クリックでチェックアウト / Sync / Revert → 結果通知 アーキテクチャ（開発用）モジュール構成と依存ui/ と core/、Maya / Blender への接続、設定・ファイル操作・連携
